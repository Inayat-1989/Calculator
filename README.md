This is a basic calculator with basic functionalties.

Technologies Used:
1. Simple HTML
2. Simple CSS
3. Simple JS with DOM

Functionalities:
1. Addition, Subtraction, Multiplication, Division.
2. Try catch block for error handling.
3. edge cases
4. simple trignometric function (sin, cos, tan)
5. square and square root and percentage
6. answer and history provided
7. dynamic insertion of values
8. infix to postifx conversion
9. postfix evaluation
10. if no two operands for addition and subtraction auto solve. (-6 won't raise error, nor +6) no strict requirement of two operands for addition and subtraction only
11. flex box and dynamic display, extendable UI design
12. seperate of concerns
13. proper file management and module management.
